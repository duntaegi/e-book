# 내 서재 (개인용 EPUB 리더)

빌드 과정이 없는 정적 사이트입니다. 이 폴더의 내용을 그대로 GitHub Pages에 올리면 됩니다.

## GitHub Pages 배포
1. GitHub에서 새 저장소를 만듭니다. (예: `my-reader`)
2. zip을 풀어서 **안의 파일들**(index.html, app.js, lib/ 등)을 저장소 맨 위에 올립니다. (폴더째 올리면 주소가 달라집니다)
3. 저장소 Settings → Pages → Source: `Deploy from a branch`, Branch: `main` / `(root)` → Save
4. 1~2분 뒤 `https://<아이디>.github.io/my-reader/` 로 접속됩니다.

## 아이패드에서 쓰기
Safari로 접속 → 공유 버튼 → **홈 화면에 추가**. 전체 화면 앱처럼 열리고 오프라인에서도 실행됩니다.

## 알아둘 점
- 책 파일, 읽던 위치, 북마크, 메모는 **쓰는 기기의 브라우저(IndexedDB)에만** 저장됩니다. GitHub에는 올라가지 않으므로 사이트 주소가 공개돼도 책은 보이지 않습니다. (아래 '기기 동기화'를 켠 경우에만 읽던 위치·북마크·독서 기록이 Firebase로 올라갑니다. 책 파일은 어떤 경우에도 올라가지 않습니다.)
- 다른 기기에서 읽으려면 그 기기에서도 **같은 epub 파일**을 따로 추가해야 합니다. 책은 파일 내용으로 구분하므로 같은 파일이면 같은 책으로 인식됩니다.
- 서재의 "백업"으로 북마크·메모·진행도를 JSON으로 저장/복원할 수 있습니다. (책 파일은 포함되지 않음)
- 코드를 수정해서 다시 올린 뒤 화면이 그대로면 `sw.js`의 `const V = 'reader-v1'` 숫자를 올려주세요.
- epub 처리에는 epub.js 와 JSZip(lib/ 폴더, 오픈소스)을 사용합니다.

## 기기 동기화 (아이패드 ↔ 폰)
서재 위쪽의 **동기화** 버튼으로 켭니다. 같은 동기화 코드를 넣은 기기끼리 **읽던 위치 · 북마크 · 독서 기록**이 몇 초 안에 맞춰집니다.
1. 처음 켜는 기기에서 **새 코드 만들기** → 20글자 코드가 나옵니다.
2. 두 번째 기기에서 **코드 입력**에 그 코드를 넣습니다.
3. 두 기기에 같은 epub 파일을 각각 추가해 둡니다. (책이 없는 기기에도 위치는 미리 도착해 있다가, 책을 추가하면 이어서 읽을 수 있어요.)

- 같은 항목을 두 기기에서 바꿨다면 더 나중에 바꾼 쪽이 남습니다. 인터넷이 없을 땐 모아 뒀다가 연결되면 올립니다.
- 읽는 중인 책에 다른 기기의 더 최근 위치가 도착하면 "이동할까요?" 하고 물어봅니다.
- 보기 설정(글자 크기·테마 등), 폴더·순서는 기기마다 따로 씁니다.
- 서버: Firebase Firestore 무료 요금제(`ebook/{동기화 코드}/d/...`). 코드를 아는 사람만 기록을 읽을 수 있습니다. 규칙은 Firebase 콘솔의 Firestore > 규칙에 있습니다.
- 코드는 `sync.js`, 읽는 쪽 연결은 `app.js`의 `window.__reader`와 `DB.onWrite`입니다. 코드를 고쳐 올릴 땐 `sw.js`의 `V` 숫자를 올려 주세요.
